# Apple App Store

- [ ] In-app account deletion exists if accounts can be created.
- [ ] Sign in with Apple offered if any third-party login (Google, Facebook) is offered in the iOS app; otherwise N/A.
- [ ] Privacy policy URL is live, public and matches collected data; the same URL is in the app and in App Store Connect.
- [ ] App Privacy answers match reality: email, user content, optional photo, nickname; tracking = none unless an SDK tracks.
- [ ] Every permission has a clear usage string; the app still works if the user denies it.
- [ ] No placeholder content, "coming soon" dead ends, broken buttons or lorem ipsum. Planned features are clearly informational and nothing is locked behind a payment that does not exist.
- [ ] No mention of other platforms or competitors; no references to beta/test builds in the UI.
- [ ] Any paid feature uses in-app purchase, not an external payment link.
- [ ] A demo account and review notes are ready if sign-in is required.
- [ ] Support URL and contact email work.
- [ ] Screenshots are real screens of the current build at the required device size.
- [ ] Age rating questionnaire answered honestly; export compliance (encryption) answered.
- [ ] App name, subtitle, keywords: no trademarks you do not own, no keyword stuffing.
- [ ] Runs on the minimum iOS version declared and on the smallest supported iPhone.
